## 🆘 Support & Troubleshooting

Running into issues? Try these quick fixes first:

- Re-download the installer and reinstall.

### The app looks blurry
- This is a display scaling issue. Right-click the app icon, go to "Properties" → "Compatibility" → "Change high DPI settings" → enable "Override high DPI scaling behavior."
